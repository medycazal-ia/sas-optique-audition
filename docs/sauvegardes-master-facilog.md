# Sauvegardes MASTER-FACILOG

Suivi des sauvegardes complètes du projet livrées au fondateur (archive ZIP
autonome, hors du dépôt git, contenant une copie du code source + un guide de
restauration) — demandées quand le fondateur veut un filet de sécurité
indépendant de GitHub, capable de recréer le logiciel dans une future session
Claude Code qui n'aurait pas la mémoire de celle-ci.

Convention de nommage : `MASTER-FACILOG-vN`, N incrémenté à chaque nouvelle
sauvegarde. Le contenu de chaque archive (code source au commit indiqué,
liens vers le mode d'emploi en vigueur à cette date, instructions de
restauration) est décrit dans son propre `README-RESTAURATION.md` interne —
ce fichier-ci ne sert qu'à savoir, depuis le dépôt, quelle est la dernière
version faite et à quel commit elle correspond.
